# Drone_pilotable_mains
Le but de ce projet est de créer un drone pilotable par des signes de mains. Il est capable de suivre un visage ou d'effectuer des mouvements grâce à des signes de mains. Il fonctionne avec des fichiers python constituants 2 noeuds ROS2. Le noeud driver fait la liaison matérielle, le noeud cerveau contrôle le drone.
